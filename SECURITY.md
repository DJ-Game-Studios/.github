# Security policy

## Supported versions

Security fixes are considered for the most recent public release or the current default branch of a maintained public tool. Legacy archives and older community-test builds may not receive fixes.

## Report a vulnerability

1. Open the affected repository’s **Security** tab.
2. If **Report a vulnerability** is available, use it to send a private report.
3. Include the affected version, impact, reproduction steps, and the smallest safe proof of concept.

If private vulnerability reporting is unavailable, open a public issue containing only a request for private reporting instructions. Do **not** include exploit details, credentials, private data, or logs that expose local paths or tokens.

Please allow maintainers time to reproduce and assess the report before public disclosure. DJ Game Studios maintains public projects on a best-effort basis and does not promise a fixed response or remediation window.
