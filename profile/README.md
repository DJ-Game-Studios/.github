## Helix MMORPG

**Helix MMORPG is our flagship and primary development focus:** a 3D, fantasy-first persistent world centered on evolution, identity, spirit, and transformation.

The current mainline is built in Rust around a custom `wgpu`/`winit` client, a QUIC game server, shared game and data foundations, and an in-house world and asset pipeline. It is under active private development.

## The wider Helix slate

- **Helix 2000** — an active 2D browser MMORPG and a different expression of the same world.
- **Helix Card Online** — an active online card-game branch.
- **DJ-Engine** — an independent Rust engine supporting adjacent Helix games and experiments.
- **Helix tools and data** — the private foundations behind characters, world data, assets, validation, and production workflows.

Helix is the main universe. Genre experiments and alternate interpretations do not replace the flagship direction.

## Studio infrastructure

We also build the Linux workstation, desktop-automation, production, and release tooling that keeps a small studio moving. Public utilities such as **DJ Mouse Warp** and **DJ GNOME Focus** are real parts of that work: they solve problems encountered across the boxes used to build, test, capture, and operate our games.

## What is public here

Core game source remains private by default. Public repositories fall into two deliberate categories:

- **Release channels and installable packages** for players and creators.
- **Reusable studio infrastructure** that can help people working on similar Linux setups.

They are authentic parts of DJ Game Studios, but they are not a complete map of the portfolio or an indication that every public utility is a flagship product.

When a Helix MMORPG build is ready for public testing, its download and release notes will appear here.
